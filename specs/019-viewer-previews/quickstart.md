# Quickstart: Viewer Previews (GUI check)

Run on the test copy of the app (own bundle id), never the installed app. All files live in the
session's scratch folder; the check only reads them.

## Setup

1. Make a folder `prev/` in the scratch folder with:
   - `small.json` (nested objects and arrays, a key with a space, a duplicate key, the number
     `12345678901234567890.5`), `min.json` (a minified ~10 MB file generated by a script),
     `big.json` (~25 MB), `bad.json` (an error on line 3), `comments.jsonc` (comments and a trailing
     comma), `items.ndjson` (three lines, the second broken);
   - `icon.svg`, `script.svg` (a `<script>` and an `<image href="http://127.0.0.1:<port>/x.png">` with a
     local `python3 -m http.server` logging requests), `icon.svgz` (gzip of icon.svg), `broken.svg`;
   - `tone.wav`, `tone.mp3`, `tone.m4a`, `tone.flac` (made with `afconvert` from a generated tone),
     `clip.mov` / `clip.mp4` (made with `avconvert` or a tiny generated movie);
   - `Program.fs`, `Index.cshtml`, `App.sln`, `Directory.Build.props`, `Lib.fsproj`, `Pkg.nuspec`.
2. Point the left panel to `prev/`.

## Checks

1. **Formatted JSON**: F3 on `small.json` → Preview with the document indented and highlighted, keys
   in file order, the duplicate key twice, the big number as written; ⌘F / ⌘G find a nested key; a
   selection copies with ⌘C; Wrap Lines and zoom work; ⌘1 shows the source as written; Space moves to
   the next file.
2. **Speed**: F3 on `min.json` shows the formatted text within 2 s and the window stays responsive.
3. **Large**: F3 on `big.json` (26 MB) → "Formatting…" in the status line, then the formatted text
   within about 5 s, with no question.
4. **Errors**: `bad.json` opens in Text with "line 3, column …" and Preview disabled; `comments.jsonc`
   is formatted without its comments; `items.ndjson` formats lines 1 and 3, keeps line 2 as written and
   names it in the status line.
5. **SVG**: F3 on `icon.svg` opens the viewer (not Quick Look), fitted; ⌘+ / ⌘- / ⌘0 / ⌘9; ⌘1 shows XML;
   `script.svg` draws without the script and the local server logs no request; `icon.svgz` draws;
   `broken.svg` says it cannot be shown.
6. **Media**: F3 on `tone.wav` → player, not playing; Return plays, Return pauses; → seeks 5 s; ↑/↓
   volume; details line shows duration, format, sample rate, channels; Space during playback moves to
   the next file and the sound stops; Esc while playing closes and stops; `clip.mov` shows frame size;
   ⌘2 shows bytes.
7. **.NET**: ⌘1 on each .NET file shows highlighting (F# comments `(* *)`, Razor `@` code as C#, `.sln`
   sections, XML for props/fsproj/nuspec).
8. **Stepping**: Space through the folder stays in one viewer window across JSON, SVG, media and text.
9. **Dark mode**: highlighting and player follow the system appearance (check with the test copy only).
10. Remove `prev/` at the end.
