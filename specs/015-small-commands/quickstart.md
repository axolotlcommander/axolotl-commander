# Quickstart: Small Commands

## Automated

`swift build` gives no warnings and `swift test` is green (`SmallCommandsTests`).

## GUI check (test copy, scratchpad folders only)

1. ⇧F5 on `a.txt`, Return: `a copy.txt` appears with the cursor on it. ⇧F5 on a folder with `x2`:
   a copy of the tree. ⇧F5 with the original name: an error, nothing copied.
2. ⌥⌘N on `photos.zip`: the other panel gets `photos`, the focus stays.
3. Mark two files, ⌥⇧F3 on a third: the viewer shows only that file.
4. ⌥⇧F5 on two scratch files: the archive holds them, they left the folder (Trash).
5. ⌥⇧F9 on a good zip and on a truncated copy: one OK, one with a problem.
6. ⌃⇧J (via the menu, DDM), ⌥⇧↑, Select All Files / Deselect All Files from the Edit menu.
