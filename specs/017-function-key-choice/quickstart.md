# Quickstart: Choose the Function Key Buttons

In the test copy of the app (own bundle id), panels on scratchpad folders.

1. Settings → General: twelve tick boxes under "Show function key bar", all ticked. Untick F5, F6, F8:
   the bar shows nine buttons in every window at once; hold ⇧ — no buttons at those positions.
2. Press F5 in a panel: the copy dialog opens (cancel it).
3. Untick all but F3: F3's box is disabled; the F3 button is at most 140 points wide, at the left.
4. Make the window narrow with three buttons: they shrink and share the bar evenly.
5. Tick all twelve again: the bar looks as before, with a small margin at both ends.
6. Right-click the bar → Choose Buttons…: Settings opens on General.
7. Export settings: the file holds `functionKeyBar.hidden`.
