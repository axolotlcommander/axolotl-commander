# Quickstart: Button Bar

In the test copy of the app (own bundle id), panels on scratchpad folders.

1. View → Show Button Bar: six sample icons appear above the panels; the item is checked.
2. Point at each icon: tooltips with names (and shortcuts). Click Find: Find opens; focus back in the panel.
3. Settings → Button Bar → Bottom: the icons follow F12 after a thin line.
4. Make the window narrow: the function keys shrink to their key caps, then icons go into ».
5. Add a program button `/usr/bin/touch` with a scratchpad file as argument; click it: the file appears.
6. Choose an icon in the picker (search "folder"); the bar changes at once.
7. Right-click a button → Remove Button; → Edit Button… opens Settings with it selected.
8. Export settings: the file has a `buttonBar` section and `buttonBar.placement`.
